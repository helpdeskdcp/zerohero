# Candle-AI: next-candle probability from candle patterns × Fibonacci/previous D-W-M levels × volume — pre-registered spec, 2026-10-24

Written BEFORE any result is computed. Frozen once the first number is printed; changes go in a dated addendum, never an edit.

## What is built
`app/candle_ai/`: (1) levels — previous Day/Week/Month High, Low, Close and Fibonacci pivots of each (P=(H+L+C)/3; R1/S1 = P±0.382·(H−L), R2/S2 = P±0.618·(H−L), R3/S3 = P±1.0·(H−L)), all from COMPLETED periods only; (2) ~24 candle patterns + anatomy, vectorised, using bars up to t; (3) volume-candle features (relative volume vs same-time-of-day median, close-location×volume, effort-vs-result, climax/dry-up); (4) models of P(next candle up).
Target y_t = 1 if close[t+1] > close[t] (rows with equal closes dropped). Decision at the close of bar t, nothing after t used.

## Models
- M0 base rate (train period up-share).
- M1 empirical-Bayes table: P(up | dominant pattern, level zone, trend state), shrunk to the base rate with prior strength 50.
- M2 HistGradientBoostingClassifier on all features, isotonic-calibrated on the LAST 20% (chronological) of the training window.
- B1 baseline logistic regression on only: return of bars t, t−1, time-of-day bucket.

## Data
- Primary (price patterns + levels): NIFTY and BANKNIFTY 5-minute INDEX bars 2015-01..2026-05 (Kaggle research_historical.db, duplicates removed). NO volume exists there (100% null) — volume features are NaN and excluded from the primary study.
- Volume sub-study (descriptive only): FUTURE 5-minute bars with real volume, 2026-07/09..2026-10-23 (market_history.db market_candles): NIFTY, BANKNIFTY, NATURALGAS, CRUDEOIL. About 3-4 months: a GO verdict is NOT possible from it; it only reports whether volume adds AUC over price-only, with a day-block bootstrap CI.

## Walk-forward (primary)
Expanding window, test = one calendar year, train = all earlier years, 1-day embargo. Test years 2018..2026. P1 = test years 2018-2021, P2 = 2022-2026. No parameter is tuned on a test year.

## Gates for GO-SHADOW (ALL, on NIFTY AND BANKNIFTY, in BOTH P1 and P2, using M2 unless stated)
G1 calibration: reliability error (10 equal-width bins, count-weighted) ≤ 0.03 and calibration slope in [0.8, 1.2].
G2 discrimination: AUC ≥ 0.52 and the day-block bootstrap 95% CI lower bound > 0.50.
G3 edge after cost: signals = test bars whose calibrated p is beyond the train-set 90th percentile of |p − 0.5| (threshold fixed on train). Mean directional next-bar return in bps minus 1.0 bp round-trip cost > 0 with day-block bootstrap 95% CI lower bound > 0. (Sensitivity cost 0.5 / 2.0 bp reported, not gated.)
G4 not trivial: M2 AUC ≥ B1 AUC + 0.005 and ≥ M1 AUC + 0.005 in each cell.
Verdict: all pass → GO-SHADOW (advisory log only, NEVER an order gate); any fail with enough data → NO-GO; fewer than 5,000 signals/test cell or a CI too wide to decide → INCONCLUSIVE.

## "Which candle, in which condition" table (discovery → replication)
Cells = pattern × location (nearest level type and side, distance bucket in ATR) × trend state. Discovery on P1 (2015-2019 train data only): hit-rate vs base, binomial p, Benjamini-Hochberg FDR 0.10. A cell is REPORTED only if it keeps the same sign and p<0.05 in the P2 replication (2020+). Everything else is discarded, not shown. Costs applied to the mean next-bar return of reported cells.
