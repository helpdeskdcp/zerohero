# H-LT2 — after a level is touched: continuation (breakout) or reversal? — pre-registered spec, 2026-10-23

Written BEFORE any LT2 outcome is computed. Builds on H-LT1 (SPEC_2026-10-23.md, FINDINGS_2026-10-23.md). Frozen once the first result is printed; changes go in a dated addendum.

## Question
When price touches a level, does it more often continue through (breakout) or turn back (reversal), in both directions (level above and below)? And does the touch-bar close (closed beyond the level vs. rejected back inside) separate the two, and do structural levels behave differently from a plain price at the same distance?
Pure price study: no options, no costs, no P&L. Not a trade rule.

## Data, periods, sampling
Same as H-LT1: NIFTY 1m 2015-2025, BANKNIFTY 1m 2015-2026-04; P1 = 2015-2019, P2 = 2020+. Decision times every 10th bar 09:30-14:50; sigma10 from EWMA (halflife 30 bars) exactly as in H-LT1; P = close at the decision time; levels = the same structural set (swing H/L N=3 on 5m confirmed, previous-day H/L, opening-range H/L) within 0.25..2.0 sigma10, plus plain probe levels at d in {0.25,0.5,0.75,1.0,1.5,2.0} both sides.

## Event and outcome (fixed now)
- Touch = first bar j in t+1..t+10 whose high >= L (level above) or low <= L (level below). No touch -> no event.
- Class at the touch bar: BEYOND if its close is beyond L (above: close > L; below: close < L), else REJECTED (closed back at/inside L).
- Race from bar j+1 over at most 20 bars (must stay inside the session): CONT target = L +/- 0.5*sigma10*P (further beyond the level), REV target = L -/+ 0.5*sigma10*P (back through the level to the other side). First target reached wins; both in the same bar = NONE (pessimistic); neither = NONE.
- cont_share = CONT / (CONT + REV).

## Metrics (per instrument, per period; above/below reported separately and combined)
1. cont_share and counts for each (source = structural kinds | plain) x (class BEYOND | REJECTED).
2. Class effect (within plain levels and within structural): cont_share(BEYOND) - cont_share(REJECTED).
3. Level effect: cont_share(structural) - cont_share(plain), within each class. 95% CI by bootstrap over days (1000 resamples, seed 7).

## Pass / fail (decided now)
- CLASS SEPARATES if the class effect CI excludes 0 in the same direction in both periods and both instruments AND |effect| >= 5 points.
- LEVEL MATTERS if the level effect CI excludes 0 in the same direction in both periods and both instruments AND |effect| >= 3 points.
- Otherwise: NO SEPARATION / NO LEVEL EFFECT, stated as such. A pass here still says nothing about option P&L: a separate spec (premium, spread, costs, stop/target ladder) is required before any trade rule.

## Not claimed
No edge, no profitability. NG/Crude/GOLDM/SENSEX are not covered: no comparable multi-year 1-minute history is stored for them (SENSEX 2023 only, MCX none) — they stay shadow-only.
