# Pre-registered spec: MCX energy event-volatility hypothesis, STAGE 1 = premise test (written BEFORE any outcome was computed)

**Hypothesis H-EV.** Scheduled US energy releases (EIA crude inventories, Wednesdays ~10:30 New York = 20:00 IST while US summer time lasts; EIA natural-gas storage, Thursdays 10:30 NY = 20:00 IST) cause a volatility expansion in MCX CRUDEOIL (Wed) and NATURALGAS (Thu) futures right after the release that a long-option buyer could harvest.
**This stage tests only the premise** (does the expansion exist and is it big enough), not a trading rule. If the premise fails, H-EV is NO-GO and nothing is built. If it holds, a SEPARATE stage-2 spec (entry/exit/cost rules) will be written and committed before any strategy P&L is computed.

**Data.** `market_history.db` `market_candles`, kind FUTURE, symbols CRUDEOIL and NATURALGAS. 1-minute bars: source DHAN_HISTORICAL for session dates 2026-06-30..2026-08-31, ANGELONE_CANDLES for 2026-09-01..2026-10-20 (no mixing inside a date). Daily bars (DHAN_HISTORICAL 1d, 2021-09-29..2026-09-25) for the long-sample check. All of the 1-minute sample lies inside US summer time, so the release is 20:00 IST throughout.
**Event days.** CRUDEOIL: Wednesdays; NATURALGAS: Thursdays. **Uncertain dates (holiday shifts), excluded from the primary test and reported separately:** 2026-09-09 and 2026-09-10 (US Labor Day week), 2026-10-14 and 2026-10-15 (US Columbus Day week), and any MCX holiday / day with no bars in the window. No other date is moved or dropped after seeing data.
**Control days.** Same symbol, same clock window, Mon/Tue/Fri only (Wed/Thu excluded for both symbols, so the control never contains the other symbol's event or a neighbouring day's release), same exclusions.
**Statistic.** Window W = bars opening 20:00..20:14 IST (15 bars). Per day: range ratio = (max high - min low) / open of the 20:00 bar. Baseline window B = bars 19:30..19:44 IST the same day (pre-release); per day the relative expansion = W ratio / B ratio. Primary comparison: event-day W ratio vs control-day W ratio (difference in medians as a ratio), plus the same on relative expansion.
**Premise holds only if ALL of:** (1) median(W event) / median(W control) >= 1.5 for BOTH symbols; (2) the 95% bootstrap interval (5000 resamples, seed 7) of that ratio has a lower bound > 1.15 for BOTH; (3) one-sided Mann-Whitney p < 0.01 for BOTH; (4) the ratio is > 1.2 in BOTH sub-periods (2026-06-30..08-31 and 2026-09-01..10-20) for BOTH symbols. Failing any one => premise NOT supported.
**Long-sample check (daily bars, 5 years).** Day-of-week range ratio ((H-L)/O) of Wed vs Mon/Tue/Fri for CRUDEOIL and Thu vs Mon/Tue/Fri for NATURALGAS, with bootstrap interval. Reported as supporting/contradicting context only; it cannot rescue a failed 1-minute premise (a whole-day range includes the whole session, not the release window).
**Honesty.** n per cell will be about 15-17 event days per symbol; if n_event < 12 for a symbol the verdict for that symbol is INSUFFICIENT. Even a pass shows only that the expansion exists in a ~4-month summer sample; it is not evidence of a profitable strategy. Costs, spread and option pricing are NOT considered at this stage. The result is written unedited to `data/research/energy_event/`.
