# Intraday constituent lead-lag (do heavyweights move first and does that predict the index?) — pre-registered spec (2026-10-25, before any statistic)
Owner's mechanism: money placed in heavyweight stocks moves the index. Honest framing first: the index is an arithmetic function of its stocks, so "stocks move the index" is an identity, not a hypothesis. What is testable, and what a trader could use: does the return of the heavyweight basket over the last k minutes predict the INDEX return over the next h minutes beyond the index's own recent returns (i.e. the index lags its heavyweights, or the heavyweights lead the rest)? That is a lead-lag effect between baskets, and it either exists at 1-5 minute scale or not.
Data: Upstox 1-minute candles (v3 historical) for the 53 large caps and the NIFTY 50 index, 2024-10-01 .. 2026-10-23, stored in data/historical/stocks_1m/stocks_1m.db. Only within-session returns are used (no overnight gaps, so unadjusted corporate actions cannot matter; sessions with a >5 % one-minute move in any basket stock are dropped as data errors and counted).
Baskets: HEAVY = HDFCBANK RELIANCE ICICIBANK INFY BHARTIARTL ITC LT TCS AXISBANK SBIN with fixed approximate index weights (13, 9, 8, 5, 4.5, 4, 4, 3.5, 3, 3; normalised) ; REST = the other stocks, equal weight. 1-minute log returns.
Model (K = 2 horizons h in {1, 5} minutes; CI level 0.05/2 = 0.025): target = index log return over (t, t+h] ; features = HEAVY return lags 1..5 (1-minute each), REST return lags 1..5, index return lags 1..5. Ridge (alpha 1.0 on standardised features), fitted on 2024-10..2025-09, evaluated out of sample on 2025-10..2026-10. Statistic 1: out-of-sample R² of the full model minus R² of the index-own-lags-only model, permutation p (HEAVY/REST lag columns shuffled in blocks of one session, 2,000 permutations). Statistic 2 (trading relevance): when |prediction| is in the top 10 % of the training distribution of |prediction|, take the predicted sign for h minutes from the next minute's open (1-minute delay), cost 1.5 bp round trip (index future/ETF style, stated assumption). Day-block bootstrap CI of mean net bp per trade.
Gate (all): R² improvement > 0 with p < 0.025; n trades >= 300; mean net bp > 0; CI lower bound > 0 (level 0.025); both halves of the test year positive. Otherwise NO-GO. Reported: the same statistics for HEAVY-only features and REST-only features (which basket carries any information), coefficient signs.
Limits: approximate weights; 1-minute candles are not ticks (lags below 60 s are invisible); a pass would only license an observation-only feed.
