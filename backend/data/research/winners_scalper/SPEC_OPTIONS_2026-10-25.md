# Winners Scalper (15m, trailing exit) on real option premiums — pre-registered spec, 2026-10-25, before any option price is read
Why: the index-level pass (net +0.10 R, ~4 bp/trade) is not what the arena trades. The arena trades option premiums. Earlier index edges of a few bp have not survived option spread/theta/STT.
Signals: exactly the pre-registered X2 / 15m signals and exits of SPEC_2026-10-25.md (same code, app/winners_scalper), NIFTY and SENSEX only (the two underlyings with a weekly 1-minute option database: 108 / 107 expiries, 2024-10 .. 2026-10). Only signals inside that period.
Contract: BUY signal -> long ATM CALL, SELL signal -> long ATM PUT, one lot (NIFTY 65, SENSEX 20), of the weekly expiry whose stored sessions contain the signal day. ATM = the strike nearest to the open of the entry bar.
Timing: all entries and exits are at 15-minute bar boundaries. Entry = boundary at the start of the bar after the signal bar; price = close of the option's 1-minute bar that ends at that boundary (known then). Exit boundary = the end of the bar in which the stop was touched, the start of the bar after a direction flip, or 15:15 (so stop-outs are bar-close-confirmed, not intrabar - a stated change versus the index simulation, which assumed intrabar stops).
Fills: slippage 0.5 point (NIFTY) / 2.0 points (SENSEX) per side against us; costs from app/institutional_edge/costs.estimate_index_option_cost (brokerage 2 x Rs 20, exchange, STT 0.15 % on the sell side, stamp, SEBI, GST; its own slippage term set to 0 because slippage is applied to the prices).
Cells (K = 4, CI level 0.05/4 = 0.0125): {NIFTY, SENSEX} x {DTE >= 1 only, all days incl. expiry day}. P&L in rupees per trade per lot, net.
Gate (all): n >= 80 per cell; mean net P&L > 0; day-block bootstrap CI lower bound (level 0.0125) > 0; positive in both halves of the sample. Otherwise NO-GO (INSUFFICIENT_SAMPLE if n < 80).
Reported, not gated: the same trades' index-level P&L with bar-close exits (control: how much the exit-timing change alone costs), win rate, premium-return per trade, worst loss, premium bucket (cheap OTM-like vs expensive), by-year split.
Limits: closes not bid/ask; two years, one regime; 2020 (the year carrying half the index-level result) is outside the option data; a pass would license observation-only forward tracking, never orders.
