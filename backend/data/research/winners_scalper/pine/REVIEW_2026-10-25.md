Files: WSP_v45_IN_original.pine (the owner's script, paste chunks re-joined), WSP_v45_IN_reviewed.pine (the reviewed one to paste into TradingView).

## Verification done here
- Both files run in the Smart Chart's Pine interpreter (PineTS) with no error.
- Signal parity, 6,000 real NIFTY 15m bars: original vs reviewed vs the Python port - BUY 0 mismatches, SELL 0 mismatches, `dir` exact, stop lines / ATR / ADX within 2e-10. (A real porting bug was found this way: while the 34-bar SMA is still na, `close > na` is false but the `or` branch can still be true; fixed in the port. - NOT verified: compilation on TradingView itself (no access) and the content of the alert() JSON (the Smart Chart runtime does not record alert() calls). Paste the reviewed script into TradingView; if the compiler reports an error, send the line number.

## Findings (what the review changed) - signal logic untouched
| # | Finding | Why it matters | Change |
|---|---|---|---|
| R1 | request.security without explicit gaps/lookahead | repaint/ambiguity risk | explicit gaps_off / lookahead_off; the [1]+lookahead_on form for previous-day levels and the HTF trend kept on purpose |
| R2 | RSI length assigned inside an `if` | can become `series int`, which ta.rsi rejects on some compilers | one expression |
| R3 | ta.sma inside a `switch` branch | ta.* should run unconditionally on every bar | all three MAs computed, then selected |
| R4 | `ta.barssince(...) >= minBars` while barssince is na | silently suppresses every signal before the first flip of the loaded history | made explicit (behaviour identical; documented) |
| R5 | signals computed on the live bar | labels/alerts can appear and vanish intrabar (repainting); the back-test assumes bar-close signals | new input 'Signals on bar close only' (default ON) gating labels and alerts |
| R6 | alert text had only ticker and price | no stop / targets for a manual trade | new alert() JSON: side, entry, sl (stop line), tp1-3, atr, strong |
| R7 | Risk Gauge / VIX / DXY | only feeds the dashboard; back-tested as an entry filter: no benefit | documented, not changed |
| R8 | volume layers on spot indices | inert without a futures proxy; none touches a signal | documented |

## How to use (TradingView free plan)
Chart NIFTY / BANKNIFTY on 15m (the only timeframe with a (fragile) index-level edge; option-premium test 2024-26: about zero). Create an alert on the indicator with 'Any alert() function call' (JSON, includes the stop and targets) or on 'Buy Signal (All)' / 'Sell Signal (All)'. App/email notifications work on the free plan; webhooks do not.
