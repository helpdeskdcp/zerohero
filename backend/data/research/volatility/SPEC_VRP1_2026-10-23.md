# H-VRP1 — is the NIFTY ATM straddle mispriced against the day's realised move? — pre-registered spec, 2026-10-23

Written BEFORE any data is pulled or any outcome computed. Frozen once the first result is printed; changes go in a dated addendum. STAGE 1 is a premise test (no costs, no trade rule). Stage 2 exists only if Stage 1 passes.
A different hypothesis class from the closed price-pattern studies (H-LT1/LT2/GAP1 and earlier): it uses the option PRICE, not the index path alone. Closed and not repeated here: NIFTY weekly Iron Condor intraday (NO-GO), expiry-day straddles (NO-GO, NIFTY -261 / SENSEX -536 Rs per trade), index-event option-level (NO-GO).

## Question
At 09:30 the market quotes an ATM straddle that implies an expected move by 15:14. Is the ratio of that implied move to what the index has typically moved over the same window recently (x) informative about how the realised move turns out against the straddle (rho)?
If the straddle is, say, cheap relative to recent same-window moves, is the realised move larger relative to the premium than usual (and the reverse when it is rich)?

## Data (to be pulled read-only, per day, after this spec is committed)
- Upstox expired-options importer: NIFTY weekly options, 1-minute OHLC + volume + OI, ATM +/- 5 strikes, about 2025-09 .. 2026-09 (about 50 weekly expiries), plus NIFTY index 1-minute. Query per day; no bulk load (it OOMs). Disk: about 7 GB, delete after the study (as before), free space checked first.
- Limit declared up front: only about 250 sessions exist, one regime year. Two halves (H1 = first half of sessions, H2 = second half) replace two independent multi-year periods. The result can be INSUFFICIENT_SAMPLE by design.

## Definitions (fixed now)
- Day d, nearest weekly expiry E (DTE = calendar days to E, 0..6). Spot S0 = NIFTY index close of the 09:29 bar; K0 = strike nearest S0.
- Straddle premium V0 = close of the 09:29 bar of the K0 CE + close of the K0 PE (last-traded proxy: no bid/ask in this data). Days with a missing leg bar at 09:29 are skipped and counted.
- Realised move M = |index close of the 15:14 bar - S0|. Realised straddle value at 15:14 = intrinsic proxy |S1 - K0| is NOT used; the traded value is the option bars' closes at 15:14 (V1 = CE close + PE close at 15:14), for Stage 2 only.
- Historical same-window move: Hm = median over the previous 20 sessions of |index close(15:14) - index close(09:29)|. Needs 20 prior sessions.
- x = V0 / Hm  (cheap if low, rich if high). rho = M / V0  (above ~1 means the straddle underpriced the realised move).

## Stage 1 (premise, no costs)
Per half and over all days, separately for DTE = 0 (expiry day) and DTE >= 1:
1. Spearman correlation between x and rho. Expected sign if the hypothesis holds: negative (rich premium -> the move covers less of it).
2. Mean rho in the lowest x tercile minus the highest x tercile, with a 95% bootstrap interval over days (2000 resamples, seed 7). Terciles are cut within each group (DTE = 0, DTE >= 1) and each half.
3. Descriptive: median V0/S0 and median rho by DTE.
PREMISE HOLDS only if, for DTE >= 1 (the larger group), the Spearman correlation is negative with |r| >= 0.20, and the tercile difference has a bootstrap interval excluding 0 on the same side, in BOTH halves. The DTE = 0 group is reported but cannot rescue or sink the test (too few days: about 50).
If the premise fails: H-VRP1 is NO-GO, nothing is built, the data is deleted.

## Stage 2 (only if Stage 1 holds; written as a separate addendum BEFORE any P&L is computed)
Candidate rule for the addendum, fixed now so it cannot be tuned afterwards: long ATM straddle (1 lot, qty = NIFTY lot) at the 09:30 snapshot only when x is in the lowest tercile of its group, exit at 15:14, no stop. Net P&L uses V1 - V0 per share, minus costs: AngelOne option brokerage and statutory charges for both legs and a pessimistic 1.5 percent of premium per side for spread/slippage (no bid/ask exists in this data). Gate: mean net per trade > 0 with a 95% interval above 0 in both halves, n >= 30 trades per half. Selling the rich tercile is NOT part of this spec (open-ended risk; a defined-risk version needs its own spec).

## What this spec does not claim
No edge. Last-traded closes are not executable prices. One year is one regime. A Stage 1 pass would show only that the premium carries information about realised vs implied move, not that it can be traded after costs.
