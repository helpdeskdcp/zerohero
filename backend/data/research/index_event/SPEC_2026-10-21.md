# Pre-registered spec: index expiry-day premise tests, H-IDX family (written BEFORE any outcome was computed)

**Principle (agreed with the project owner).** One rule per instrument, active only on its own days; no strategy is reused across indices. Each index below is its own hypothesis with its own premise test. A family of 3 hypotheses is tested, so the p-value bar is Bonferroni-adjusted: **alpha = 0.01 / 3 = 0.0033**.

**Hypotheses.** For each of NIFTY, BANKNIFTY, SENSEX: "on its option-expiry day the last part of the session (14:30-15:15 IST) has a materially larger index range than on ordinary days" (the gamma-expiry effect that a long-option scalper would try to harvest). This stage tests ONLY the premise (volatility expansion), not a trading rule or P&L.
**Data.** `market_history.db` `market_candles`, kind INDEX, tf 1m, source DHAN_HISTORICAL, session dates 2024-09-01..2026-09-28 (the earlier part is only used as the 20-day baseline for the first expiry days). Expiry days = the broker contract metadata list in `app/hist_options/data/expiry_metadata_upstox.json` (actual expired expiries, holiday shifts included); an expiry date is used as listed. No other date is added or moved.
**Window W** = bars opening 14:30..15:14 IST (45 bars; a day needs >= 40 of them, else it is skipped and listed). Day statistic: range_W = (max high - min low) / open of the first bar.
**Baseline per expiry day.** median of range_W over the 20 most recent trading days before it that are NOT an expiry day of the same index (need >= 10, else the expiry day is skipped and listed). **Day ratio** = range_W(expiry day) / baseline.
**Premise holds for an index only if ALL of:** (1) median day ratio >= 1.30; (2) the 95% bootstrap interval (5000 resamples, seed 7) of the median day ratio has a lower bound > 1.10; (3) one-sided Wilcoxon signed-rank test of log(ratio) > 0 has p < 0.0033; (4) the median ratio is > 1.15 in BOTH halves of the sample (split at the median expiry date); (5) n >= 30 expiry days (else INSUFFICIENT).
**Not considered at this stage:** costs, spreads, option pricing, direction. Even a pass says nothing about profitability; a long option bought into expiry already prices the expected expansion. If a premise passes, a SEPARATE stage-2 spec (rule + real-option-premium backtest, e.g. the Upstox expired-option 1-minute bars, which can be re-pulled) will be written and committed before any P&L is computed. Failing indices are dropped.
**Honesty.** Result written unedited to `data/research/index_event/`. Skipped days are listed, not hidden. BANKNIFTY's expiry list changes in structure (weekly until late 2024, monthly after): all listed expiry days are pooled and the structure change is stated, not corrected.
